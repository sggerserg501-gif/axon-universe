# 🧠 OpenNeuroAtlas 3D — Открытый медицинский 3D-атлас
### 🌐 **[Открыть живой 3D-атлас в браузере ↗](https://sggerserg501-gif.github.io/axon-universe/)**


**OpenNeuroAtlas 3D** — интерактивный медицинский 3D-атлас с открытым исходным кодом, написанный на чистом HTML5 Canvas и Vanilla JavaScript (без сторонних библиотек и зависимостей). Платформа создана для врачей, студентов-медиков и пациентов для наглядной визуализации анатомии, стадий патологий и клинической тактики.

---

## ✨ Основные возможности

- **7 интерактивных 3D-моделей:**
  1. **Позвоночник** (Анатомическая норма, протрузия диска, грыжа с компрессией корешка)
  2. **Головной мозг** (Норма структур мозга, сосудистый спазм, очаговое давление / масс-эффект)
  3. **Нейрон и Аксон** (Норма проведения импульса, демиелинизация, блокада аксона и синапса)
  4. **Сосуды мозга** (Виллизиев круг, функциональный ангиоспазм, мешотчатая аневризма)
  5. **Шейный отдел (C4–C6)** (Норма шеи и артерий, синдром позвоночной артерии, шейная миелопатия)
  6. **Сердце и сосуды** (Норма ритма и коронаров, коронарный спазм / стенокардия, окклюзия артерии)
  7. **Вены ног и варикоз** (Норма клапанов, венозный рефлюкс, варикозные узлы и риск тромбоза)
- **Мультиязычность (5 языков):** Полный перевод интерфейса, клинических карточек и выносок на 3D-моделях на **Русский (RU)**, **Английский (EN)**, **Испанский (ES)**, **Немецкий (DE)** и **Китайский (ZH)**.
- **Режим врача и автопроверка:** Встроенный редактор позволяет специалистам предлагать корректировки клинических описаний, проходить автоматическую проверку стиля, экспортировать базу в JSON и отправлять правки напрямую в GitHub.
- **Нулевые зависимости:** Работает плавно на компьютерах и смартфонах без нагрузки на WebGL и сторонних фреймворков.

## 🚀 Быстрый запуск

1. Скачайте или клонируйте репозиторий:
   ```bash
   git clone https://github.com/sggerserg501-gif/axon-universe.git
   ```
2. Откройте файл `index.html` в любом современном браузере.

## 🩺 Как врачу внести правку в атлас

Врачи и исследователи могут предложить уточнения клинической тактики прямо из интерфейса программы:
1. Нажмите кнопку **«Режим врача»** в верхней части боковой панели.
2. Укажите ваши **ФИО, ученую степень и клинику**.
3. Отредактируйте описание или тактику лечения и нажмите **«Проверить и применить»**.
4. Нажмите **«Отправить правку в GitHub ↗»**, чтобы создать готовую заявку на рассмотрение.

> **Дисклеймер:** Проект носит исключительно образовательный и демонстрационный характер и не заменяет очную консультацию специалиста, диагностику или назначение лечения.

# 🇬🇧 OpenNeuroAtlas 3D — Interactive Open-Source Medical Atlas

**OpenNeuroAtlas 3D** is an open-source interactive 3D medical atlas built with pure HTML5 Canvas and Vanilla JavaScript (zero external dependencies). Designed for physicians, medical students, and patients to visualize anatomy, pathology stages, and clinical decision-making across **7 interactive modules** in **5 languages (RU, EN, ES, DE, ZH)**.

## ✨ Key Features

- **7 Interactive 3D Anatomical Modules:** Spine, Brain, Neuron & Axon, Brain Vessels (Circle of Willis), Cervical Spine (C4–C6), Heart & Coronary Vessels, and Leg Veins & Varicose.
- **Multilingual Support (5 Languages):** Full UI, clinical cards, and 3D callout translations in **Russian (RU)**, **English (EN)**, **Spanish (ES)**, **German (DE)**, and **Chinese (ZH)**.
- **Doctor Mode & Auto-Validation:** Built-in clinical editor allowing specialists to propose updates, validate medical style, export JSON, and submit review requests directly to GitHub Issues.
- **Zero Dependencies:** Runs smoothly on desktop and mobile browsers without WebGL overhead or third-party libraries.
